# SmartPresence – AI Powered Attendance System

## Overview
SmartPresence is an AI-based attendance management system that automates attendance using facial recognition and audio verification. The system reduces manual work, improves attendance accuracy, and prevents proxy attendance using machine learning and computer vision techniques.

---

## Features
- Face Recognition Attendance
- Audio Verification System
- Student Login Portal
- Teacher Dashboard
- Real-Time Attendance Tracking
- SQL Database Integration
- Attendance Report Management
- Secure Authentication

---

## Tech Stack
- Python
- OpenCV
- Face Recognition
- Streamlit
- SQL
- Scikit-learn
- NumPy
- Pandas

---

## SQL Usage
SQL is used in this project to:
- Store student details
- Maintain attendance records
- Retrieve attendance history
- Authenticate users
- Manage attendance reports efficiently

---

## Project Workflow
1. User logs into the system
2. Camera captures face image
3. AI model recognizes the student
4. Attendance is marked automatically
5. Attendance data is stored in SQL database
6. Teacher dashboard displays records
